Why this structure
The prompt is structured as a coding handoff rather than an open-ended request, so it skips variables (the file path and code are hardcoded) and goes straight to a complete output contract.
The current hero.tsx source is embedded verbatim so the CLI instance has full context without needing filesystem access.
The "Signal Pulse" orb concept was chosen specifically to match the product ethos: ColdHook is about sending outreach and getting responses — concentric rings pulsing outward from glowing orbs directly evokes that "signal going out" metaphor without being heavy-handed.
The stagger timing (0.12s between children, [0.22, 1, 0.36, 1] cubic bezier) follows the Vercel/Linear school of easing — that custom bezier is a snappy deceleration curve that feels fresh and modern without being overdone, which matches the "professional but push the curve a little" brief.
The constraint to use only transform and opacity is explicit because those are the only GPU-composited properties — anything else (height, padding, color outside of filter) would cause layout recalculation and jank.
The framer-motion v12 import note is included because v12 changed some APIs vs v10/v11, and CLI Claude may default to older patterns without the reminder.
