Why this structure
Each animation technique is chosen for a specific purpose. useInView gates all animations so they only fire when the section is visible — this prevents the common mistake of animations playing off-screen. Bar width is animated via motion.div (not CSS transition) so framer-motion controls the spring physics and we can stagger each bar independently. The blinking dot uses an infinite scale+opacity loop rather than CSS because it stays in sync with React render cycles. The count-up hook uses requestAnimationFrame for smooth 60fps counting with no layout thrash. Card shadows are layered (ambient + directional + top-edge highlight) to simulate physical depth without 3D transforms.
