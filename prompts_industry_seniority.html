ColdHook — Industry & Seniority Calibration

2 prompts · Run in order

What this adds: The generation pipeline currently produces the same tone and abstraction level regardless of whether the prospect is a CEO at a bank or a VP at a devtools startup. The research shows this is a major quality gap — C-suite needs strategic framing (board narrative, competitive position, 18-month outlook), VPs need operational framing (scaling pain, hiring, systems), and industry determines formality (tech/SaaS: informal; fintech/healthcare/legal: formal, careful with claims).

Prompt 1 (route.ts): Adds classifySeniority() and classifyIndustry() functions. Updates generateInsight() to factor in both. Updates buildDraftPrompt() with seniority-aware abstraction levels and industry-aware tone calibration. Also fixes a silent mismatch: compose sends bold / curious tone and calendar / question CTA values that the route wasn't mapping — those now have proper handlers.

Prompt 2 (compose/page.tsx): Adds an Industry dropdown to the Email Settings card. Adds industry state. Sends industry in both the generate and generate-sequence fetch bodies.

Order matters: Run Prompt 1 (route) first, then Prompt 2 (compose UI).

  function classifySeniority(title: string): SeniorityLevel {
    const t = title.toLowerCase()
    if (/\b(ceo|cro|cto|cmo|cfo|coo|cpo|chief|founder|co-founder|president|owner)\b/.test(t)) return "c_suite"
    if (/\b(vp|vice president|head of|svp|evp|senior vp|group vp)\b/.test(t)) return "vp"
    if (/\b(director|sr\. director|senior director|principal)\b/.test(t)) return "director"
    return "manager_ic"
  }

  function classifyIndustry(industry: string): IndustryVertical {
    const i = industry.toLowerCase()
    if (i.includes("finance") || i.includes("fintech") || i.includes("banking") || i.includes("investment")) return "fintech_finance"
    if (i.includes("health") || i.includes("medical") || i.includes("pharma") || i.includes("clinical")) return "healthcare"
    if (i.includes("legal") || i.includes("law") || i.includes("compliance")) return "legal"
    if (i.includes("manufactur") || i.includes("industrial") || i.includes("logistics") || i.includes("supply chain")) return "manufacturing"
    if (i.includes("agency") || i.includes("creative") || i.includes("marketing agency") || i.includes("design studio")) return "agency"
    return "tech_saas"
  }
