ColdHook — First-Run Onboarding Tour

3 prompts · Run in order

What this builds: A spotlight-based click-through onboarding tour for first-time users. When a new user (zero emails in DB) lands on the dashboard, they see a focused first-run hero state with a single CTA. Clicking it sends them to /compose?onboarding=true with a fictional example prospect pre-filled. A spotlight tour activates — dimming everything except the element being explained, with a bubble tooltip and Next/Skip navigation. Steps guide them through: trigger field → value prop → generate button → pipeline panel (auto-fires after generation) → sequence section (auto-fires after generation). Tour completes when they generate the sequence. Stored in localStorage so it never shows again.

Spotlight effect: Fixed div sized to the target element's bounding rect, box-shadow: 0 0 0 9999px rgba(1,1,2,0.85) creates the darkened surround. Smooth transition between steps. Bubble positioned below or above depending on screen position. No click-blocking — the tour guides, doesn't trap.

Order matters: Prompt 1 (tour component) → Prompt 2 (dashboard) → Prompt 3 (compose). Do not skip steps.

HOW IT WORKS — data-tour attribute system
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The tour finds elements to spotlight by querying document.querySelector('[data-tour=""]'). The compose page adds data-tour attributes to specific elements. The tour component does not receive refs — it queries the DOM directly by data-tour ID.

SPOTLIGHT STATE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The component tracks spotlightRect: { top, left, width, height } | null in state.

On every currentStep change (useEffect):
1. Query document.querySelector('[data-tour="${step.tourId}"]')
2. If found, call getBoundingClientRect()
3. Set spotlightRect to { top, left, width, height } from the rect
4. Also scroll the element into view: element.scrollIntoView({ behavior: 'smooth', block: 'center' })
5. If not found, set spotlightRect to null

Also add resize and scroll event listeners (passive) that re-query and update spotlightRect when the window changes. Clean up on unmount.

  const BUBBLE_WIDTH = 320
  const BUBBLE_GAP = 16  // gap between spotlight edge and bubble

  If step.position === "top" OR spotlightRect.top > window.innerHeight * 0.6:
    // Place bubble ABOVE the spotlight
    top = spotlightRect.top - 8 - BUBBLE_GAP - bubbleHeight (estimate ~130px)
    left = clamp(spotlightRect.left - 8, 16, window.innerWidth - BUBBLE_WIDTH - 16)
    Show a downward-pointing caret below the bubble

  Otherwise (default "bottom"):
    // Place bubble BELOW the spotlight
    top = spotlightRect.top + spotlightRect.height + 16 + BUBBLE_GAP
