SECTION LAYOUT:

- Max width: max-w-5xl mx-auto
- Section label pill at top (same style as Pricing section): "ROI Calculator" with a TrendingUp icon, accent color, pill border
- Headline: "See what ColdHook means for your pipeline" — large, tracking-tight, white
- Subheadline: "Adjust the sliders to see the difference better reply rates make." — muted color

CALCULATOR LAYOUT — two columns (grid-cols-1 md:grid-cols-2 gap-8):

LEFT COLUMN — Inputs:
Three slider inputs, each with a label showing the current value live as the slider moves.

Input 1: "Emails per week"
  - Range: 10 to 500, step 10, default 100
  - Show current value in accent color next to label

Input 2: "Your current reply rate"
  - Range: 1 to 15 (percent), step 0.5, default 2
  - Show as X.X% next to label
  - Add a small note below: "Industry average is ~2%"

Input 3: "Average deal size"
  - Range: $1,000 to $100,000, step 1000, default 15000
  - Show as $XX,XXX formatted with commas next to label

Slider styling: full width, accent color thumb and track fill. Use CSS to style the range input:
  accent-color: #5e6ad2 (via inline style or Tailwind)

RIGHT COLUMN — Output:
A dark card (surface-1 background, hairline border, elevated shadow) showing 3 output metrics that update live as sliders change.

CALCULATIONS (compute these in the component):
  coldhookReplyRate = 0.34  (ColdHook's 34% benchmark)
  emailsPerMonth = emailsPerWeek * 4.33
  currentReplies = emailsPerMonth * (currentReplyRate / 100)
  coldhookReplies = emailsPerMonth * coldhookReplyRate
  extraReplies = coldhookReplies - currentReplies
  closeRate = 0.20  (assume 20% of replies become meetings, 20% of meetings close)
  meetingRate = 0.20
  extraDeals = extraReplies * meetingRate * closeRate
  extraPipeline = extraDeals * dealSize
  timeSavedHours = emailsPerMonth * (18 / 60)  (18 min saved per email vs manual research)

OUTPUT METRICS — display these 3 in the card:

Metric 1 (large, prominent): "Extra pipeline/month"
  - Value: extraPipeline formatted as $X,XXX,XXX
  - Color: accent (#5e6ad2)
  - This is the hero number — make it large (text-4xl font-bold)

Metric 2: "Additional replies/month"
  - Value: Math.round(extraReplies) formatted as "+XXX replies"
  - Color: success (#27a644)

Metric 3: "Research time saved"
  - Value: Math.round(timeSavedHours) + " hrs/month"
  - Color: email/orange (#ff801f)

Below the 3 metrics, add a subtle footnote:
  "Based on ColdHook's 34% avg reply rate vs 2% industry average. Assumes 20% meeting rate, 20% close rate."
  Style: text-[10px], muted color

Below the footnote, add a CTA button:
  "Start for free — see for yourself"
  Link to /sign-up
  Full width, accent background, white text, rounded-lg, py-3

ANIMATION: When any slider value changes, animate the numbers counting up/down smoothly. Use a simple useEffect with a short interval (30ms steps) to interpolate the displayed value toward the target value. This makes the output feel live and satisfying.
