2 prompts · Run in order

Problems being fixed:

1. Overlay too opaque (all steps): The dark surround at rgba(1,1,2,0.85) makes the page feel completely hidden. Reduce to rgba(1,1,2,0.72) so the user can see the app context around the spotlight.

2. Bubble clips off screen bottom (Email Settings step): The bubble always renders below the spotlight. When the target element is low in the viewport (e.g. Email Settings card), the bubble overflows below the visible area. Fix: after calculating position, check if the bubble would overflow the viewport bottom — if so, flip it above the spotlight. Also clamp the final position so it can never escape the viewport.

3. Steps 5 & 6 have no spotlight (pipeline panel / sequence): These elements only exist in the DOM after email generation. When the tour advances to those steps, the DOM query fires before the element has mounted. Fix: retry the DOM query up to 8 times with 150ms intervals until the element appears. Also, compose.tsx must auto-open the pipeline panel when the tour reaches the pipeline-panel step (so the card is expanded and scrolled into view), and pass an onStepChange callback prop into OnboardingTour for this purpose.

4. Generate step should block Next until generation completes: The user can click Next on the Generate step without actually generating, sending them to step 5 with no email and no spotlight. The Next button on the generate-btn step should be disabled and relabeled "Generate first →" when no email has been generated yet. The tour auto-advances from this step automatically after generation — the user does not click Next manually.

Order matters: Prompt 1 (tour.tsx) → Prompt 2 (compose/page.tsx). Do not skip steps.
